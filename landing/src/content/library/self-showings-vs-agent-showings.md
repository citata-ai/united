## How do self-showing lockboxes work?

A self-showing lockbox holds the key, or a smart lock replaces the key, and a scheduling system releases a code to a verified renter. The renter tours the vacant unit alone. The system logs who entered and when.

A typical self-showing flow:

1. **Book.** The renter picks a time on the listing page.
2. **Verify.** The renter scans a photo ID, takes a selfie and confirms a phone number.
3. **Get the code.** The system sends a one-time code that works only in the booked window.
4. **Tour.** The renter enters, tours, and locks up.
5. **Follow up.** The system asks for feedback and sends the application link.

Tenant Turner, one vendor in this market, says its access codes are "ID-verified" and work with SentriLock, Seros, CodeBox and other devices. It lists "VOIP scanning, ID verification, and blacklisting" as part of every showing (Tenant Turner pricing page, read 2026-10-19).

## Do self-showings cause more fraud or squatters?

Self-showings add 2 risks that agent showings reduce: rental listing scams and unauthorized entry. A person at the door is a check that a code does not replace.

**Rental listing scams.** The FTC describes a common pattern. A fake "owner" copies a real listing, cannot show the home in person, and asks for a deposit by wire, gift card or cryptocurrency. The FTC says, "Wiring money, sending gift cards, or paying by cryptocurrency is the same as sending cash." A self-showing home is an easy target, because the scammer can tell the victim to "go see it" without being there.

**Unauthorized entry.** A renter with a code is alone in an empty unit. If ID checks are weak, a person can enter, copy a key, or return later.

Ways to cut both risks:

- Post the listing only on your own site and a few known sites. Search your address each week for copies.
- Put a line on the listing: "We never ask for a deposit before a signed lease. We never accept wire, gift card or crypto."
- Use one-time codes with short windows.
- Add a door sensor or camera on the exterior entry, as local law allows.
- Check the unit after each day of showings.

When you find a copied listing, report it to the site that posted it, to local police, to your state attorney general, and to the FTC at ReportFraud.ftc.gov. Those are the 4 places the FTC lists.

## Which costs less per lease?

Self-showings usually cost less per lease when a unit needs many showings. Agent showings cost staff time for each tour, including no-shows and drive time.

Inputs we use below:

- Tenant Turner lists its MojoBox digital lockbox from $64, its MojoLock smart lock from $85, and $3.50 per Tenant Turner device per month (vendor page, read 2026-10-19). Its software plans start at $1.17 per unit (annual, unit-based Pro) or $42.50 per listing (listing-based Pro).
- The U.S. Bureau of Labor Statistics lists a median wage of $33.65 per hour for property, real estate, and community association managers (May 2025). We use that as the cost of one staff hour. It leaves out payroll taxes and car costs.

Worked example for one vacancy. These are example numbers, not averages: 12 booked showings, 1 hour per agent showing with drive time, 1 month on the market.

| Cost item | Agent showings | Self-showings |
|---|---|---|
| Staff time | 12 × 1 hour × $33.65 = $403.80 | About 1 hour of setup and checks = $33.65 |
| Lockbox | $0 | $64 one time, used on many units |
| Device fee | $0 | $3.50 for 1 month |
| Showing software | Plan cost, if any | $42.50 per listing (Pro, listing-based) |
| Total for this vacancy | About $404 | About $144 the first time, about $80 after the box is paid off |

No-shows widen the gap. An agent who drives to a no-show still spends the hour. A no-show at a self-showing costs nothing.

The math changes with your setup. Agent showings get cheaper when an on-site leasing office shows several units in one trip. Self-showings get more expensive when you add a camera, a smart lock, or extra cleanups after tours.

## How do I verify ID before a self-showing?

Verify each renter before you release the code, and apply the same steps to every renter. Consistent steps help with Fair Housing compliance and with fraud.

ID check list:

- [ ] Photo ID scan that checks the document format
- [ ] Selfie match to the ID photo
- [ ] Mobile number check (a vendor may flag VOIP or temporary numbers)
- [ ] Payment card hold or other identity check, if your vendor offers one
- [ ] One-time code that expires at the end of the booked window
- [ ] Entry and exit log saved with the renter's record
- [ ] A block list for people who broke the rules on a past tour

Keep the ID data only as long as you need it. Tell renters in plain words what you collect and why.

## Which renters prefer each type?

Renter preference depends on the situation, not on who the renter is. Choose the showing type by the unit and the renter's need, and offer both when you can.

| Situation | Better fit |
|---|---|
| Renter works days and wants an evening or weekend tour | Self-showing |
| Renter is out of town and sends a trusted person | Self-showing, with ID for that person |
| Renter has many questions about the lease or area | Agent showing |
| Unit is occupied by a current tenant | Agent showing, with proper entry notice |
| High-value home or unit with valuable fixtures | Agent showing |
| Renter with a disability cannot use the app or the lockbox | Agent showing as a reasonable accommodation |

Fair Housing: apply the same ID, booking and screening rules to everyone. Do not offer one showing type to some renters and not others based on a protected class. If a renter with a disability asks for a different way to tour, treat it as a reasonable accommodation request.

You can mix both. Use self-showings for vacant, lower-risk units and keep an agent for occupied homes and complex questions. Read more about how we see the work of [property management](/property-management).
