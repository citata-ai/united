## Which locks work with showing software?

Choose the showing platform and supported access device together. A consumer smart lock does not automatically connect to your rental showing workflow.

| System | Vendor-described use | Price reference | Main check |
|---|---|---|---|
| Rently | Self-guided tours, smart locks, shared access | Multifamily access pricing: quote only | Supported devices and showing handoff |
| ButterflyMX | Building access, intercoms, smart locks, integrations | Software $30 to $42 per apartment unit yearly; hardware separate | Full door route and installed quote |

Sources: Rently and ButterflyMX pricing pages, read on 2026-10-19. The software rate is not a per-door installed cost.

Rently's pricing page says self-touring needs an access device. Ask which model and service plan your property requires. Confirm any hub and connection needs too.

Test an appointment from booking through access expiry. Ask the vendor to show identity checks, access instructions, cancellation, and the event record. A working lock is only part of the task.

Use a property with an exterior entrance and an interior unit door in your test. The visitor needs a clear, approved route through each controlled point.

## How do you change access between tenants?

Revoke old credentials, confirm the change at the device, and issue new access through a checked handoff. Do not assume a changed lease record instantly changes every lock.

Map the source for access rights. Decide whether the property system, access platform, or staff action controls the change. Ask what happens when a sync fails.

Test a move-out in a sample account. Check the unit lock, shared entrance, parking access, and any guest credential linked to the former resident.

Keep vendor and staff credentials separate from resident access. A maintenance worker's access should follow assigned work and approved times, not a shared permanent code.

Ask how staff confirm revocation. A dashboard status is useful, but the pilot should also test whether an old credential still works at the door.

Check the move-in process with the new resident's view. Confirm how the person receives access and gets help before arriving with belongings.

Have the property team approve the timing. This guide does not authorize a lockout or define entry rights. Follow your approved local process for tenancy changes.

## Which cloud access systems suit small multifamily?

Choose a cloud access system by the building layout, staff support, and resident access needs. Small properties still need a clear recovery plan.

Rently markets smart locks and access panels. ButterflyMX markets intercoms, access control, and related devices. Both deserve evaluation only after the vendor confirms the required building setup.

List exterior doors, unit doors, gates, common areas, and delivery points. Note which users need each point and whether the route crosses another controlled entrance.

Ask an installer to inspect the actual doors and existing hardware. Confirm power, network, mounting, and service needs before treating a device price as a project quote.

Test the person who does not have a working phone at arrival. Ask what supported alternate credential or assisted route is available. Do not discover that gap during an evening lockout.

Choose who manages access after installation. The vendor, installer, owner, and property manager should have clear responsibilities. Keep an approved local contact for physical faults.

## What do they cost per door?

Request installed project cost and ongoing software cost separately because vendors can bill by different units. A price per apartment is not the price per controlled door.

ButterflyMX's pricing page separates hardware purchase from annual software fees. Its published software range appears in the opening table. The exact quote depends on features and the property setup.

Rently's multifamily pricing is custom on the page reviewed. Record quote only rather than borrowing a residential touring price for a shared building system.

Ask for hardware, installation, wiring, network work, software, support, replacement parts, and required hubs. Confirm the contract term and which changes create extra charges.

Include the existing doors that need work. A new access device may not fix a poorly closing door or a failed latch. Have the installer identify those tasks separately.

Ask how the platform charges after adding another door or property. Keep software licenses distinct from device warranties. A replacement device and continued service are different costs.

Use the same scope when comparing quotes. Keep shared entrances and unit locks in separate lines so the cost drivers remain clear.

## What are the security risks?

The main operating risks are excess access, shared credentials, failed revocation, and unclear recovery. Test those risks before rolling out more doors.

A connected lock also needs device maintenance and account control. Assign the roles that manage batteries, updates, lost credentials, and employee departures.

Use this acceptance checklist:

- **Restrict access:** Give a test user only the approved door and time window.
- **Revoke access:** Remove the user and confirm the credential stops working.
- **Test a cancellation:** Cancel a showing and inspect the remaining access rights.
- **Test an outage:** Ask the vendor and installer to demonstrate the documented failure behavior.
- **Check recovery:** Confirm an authorized local person can help without sharing unrestricted credentials.
- **Inspect logs:** Find the relevant access event and identify who can view it.
- **Remove staff:** End an admin relationship and confirm company control remains intact.
- **Review privacy:** Limit log and visitor-data access to the people who need it.

Do not treat an access log as proof of everything that occurred at a door. Ask the vendor what each event actually records.
