Arkansas gives landlords two court paths. The unlawful detainer statutes (Ark. Code 18-60-301 and on) use a 3-day notice and a writ of possession. The residential landlord-tenant chapter (Ark. Code 18-17) adds a district court eviction with a 10-day order to vacate. The official code site did not load for us, so we read the statute text on FindLaw, current as of 2024-03-28. | Tenant's time to object in unlawful detainer | 5 days, not counting Sundays and legal holidays | Ark. Code 18-60-307(a), (b) |
| District court eviction trigger for rent | Rent unpaid 5 days after due date | Ark. Code 18-17-901(b) |

## What notice must an Arkansas landlord give before filing an eviction for unpaid rent?

The notice depends on the court path you choose.

**Unlawful detainer.** Ark. Code 18-60-304(3) says a tenant who does not pay rent when due commits unlawful detainer after 3 days' notice to quit and a written demand for possession. The Attorney General's page also describes a 3-day written notice to vacate.

**District court eviction.** Ark. Code 18-17-901(b) says that for residential leases, rent unpaid within 5 days of the due date is legal notice that the landlord may start an eviction. Ark. Code 18-17-701(b) also lets the landlord end the lease if rent is 5 days late.

| Path | Notice for unpaid rent | Court | Statute |
|---|---|---|---|
| Unlawful detainer | 3-day written notice to quit and demand | Circuit court, or district court if Supreme Court rule permits | Ark. Code 18-60-304, 18-60-306 |
| District court eviction | Rent 5 days late counts as notice | District court | Ark. Code 18-17-901, 18-17-902 |

## Can an Arkansas landlord evict a tenant for a lease violation or with no cause?

Yes. Ark. Code 18-17-901(a) lists three grounds: unpaid rent, the end of the term, and a violated lease term.

**Lease violation.** Under Ark. Code 18-17-701(a), the landlord gives written notice that names the breach. The lease ends at least 14 days after receipt unless the tenant fixes the breach in 14 days. For a breach that affects health and safety, Ark. Code 18-17-702 also gives the tenant 14 days, or less in an emergency.

**No cause.** Either side may end a month-to-month tenancy with written notice at least 30 days before the end date. A week-to-week tenancy needs 7 days (Ark. Code 18-17-704). The Attorney General's page says a landlord may end a lease for any reason with proper notice.

**Holdover.** If the tenant stays after the end, the landlord may sue for possession. If the holdover is a willful breach, the landlord may also recover up to 3 months' rent or twice actual damages, whichever is greater, plus attorney's fees (Ark. Code 18-17-704(c)).

## Where does a landlord file an eviction case in Arkansas, and what does it cost?

An Arkansas landlord files in circuit court or district court. The court depends on the path.

Unlawful detainer cases go to the circuit court of the county. District court has concurrent jurisdiction if a Supreme Court rule or order permits it (Ark. Code 18-60-306). The landlord files a signed complaint and an affidavit that the landlord is entitled to possession (Ark. Code 18-60-307(a)).

District court evictions start with a complaint and a supporting affidavit signed by a person with personal knowledge of the grounds (Ark. Code 18-17-902(a)). The filing fee is set by Ark. Code 16-17-705. We did not read that section, so ask the district court clerk for the current fee.

## How long does an eviction take in Arkansas?

Arkansas evictions can be short when the tenant does not respond. Here is our calculation from the statute periods.

**Unlawful detainer path:**

1. **3 days.** Notice to quit and written demand (Ark. Code 18-60-304(3)).
2. **File and serve.** The clerk issues a summons and a notice of intention to issue a writ of possession.
3. **5 days, not counting Sundays and legal holidays.** If the tenant files no written objection, the clerk issues the writ on the court's order (Ark. Code 18-60-307(b)).
4. **If the tenant objects,** the landlord gets a hearing date and sends notice by certified mail (Ark. Code 18-60-307(c)).
5. **24 hours** after the writ is served, the sheriff can remove the tenant (Ark. Code 18-60-310(c)).

**District court eviction path:**

1. **5 days** of unpaid rent after the due date (Ark. Code 18-17-901(b)).
2. **File** a complaint and affidavit. The court orders the tenant to vacate or show cause.
3. **10 calendar days** after service. If the tenant does not appear, the court enters judgment and the sheriff evicts (Ark. Code 18-17-904).

With no objection, the fixed periods total about 2 weeks on either path, plus service time. A contested case takes longer. These totals are our calculation, not an official estimate.

## Who removes the tenant after a judgment in Arkansas?

The county sheriff removes the tenant. Ark. Code 18-60-310 sets the steps:

- The sheriff delivers a copy of the writ to the tenant, or posts it on the front door if no one is found within 8 hours.
- If the tenant is still there 24 hours after service, the landlord gives the sheriff the labor needed.
- The sheriff moves the tenant's belongings to a public warehouse or another safe storage place under the landlord's control.
- The sheriff may remove locks or barriers to get in.

A tenant who wants to stay during the unlawful detainer case must post security within 5 days of the writ. The amount is at least the unpaid rent plus rent that accrues (Ark. Code 18-60-307(e)). On appeal from district court, a tenant can stay the writ by signing a bond to pay rent as it comes due (Ark. Code 18-17-707). If the tenant misses a payment by 5 days, the stay ends.

## Is a self-help eviction (lockout, utility shutoff) legal in Arkansas?

The sections we read do not include a lockout rule we could cite. They do give the job of removal to the sheriff, under a court writ, in both paths. Ark. Code 18-60-310 and 18-17-904 both name the sheriff.

Our advice is simple: use the court. Removal without a writ is not a step these statutes describe. Ask a local attorney before you take any step outside the court process.
