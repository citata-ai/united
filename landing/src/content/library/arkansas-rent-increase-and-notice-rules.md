Arkansas law says little about rent increases. We read the landlord-tenant sections of Ark. Code Title 18 on FindLaw, which quotes the code current as of 2024-03-28. The official code site did not load for us. We also read the Arkansas Attorney General's landlord-tenant page on 2026-10-20. This table shows what each source sets.

| Rule | Limit or deadline | Source |
|---|---|---|
| Cap on increases | None in the sections we read | Ark. Code 18-17, 18-16 |
| Notice of a rent increase | At least one rental period | Arkansas Attorney General guidance |

## Does Arkansas have a cap on rent increases or rent control?

No cap appears in the Arkansas landlord-tenant code sections we read. Ark. Code 18-17 and the deposit rules in 18-16-301 to 18-16-306 do not limit how much the rent may rise. The Attorney General's page does not mention a cap either.

The code leaves rent to the parties. Ark. Code 18-17-401(a) says the landlord and tenant may include rent and the term in the rental agreement. Rent is payable at the time and place agreed, without demand or notice (Ark. Code 18-17-401(b)).

We did not find a state rent control law. We also could not open a statute that bars cities from passing one, so we do not state a rule on that point.

## How many days notice does an Arkansas landlord need to raise the rent?

The Arkansas Attorney General says at least one rental period. Its landlord-tenant page states: "Landlords must provide notice of at least one rental period before raising the rent." The page says the rule applies to both oral and written leases.

We did not find a code section that sets this period, so treat it as the Attorney General's guidance. It matches the tenancy rules: a month-to-month tenancy ends on 30 days' written notice under Ark. Code 18-17-704(b).

| Rent paid | One rental period | Example: new rent from 2027-01-01 |
|---|---|---|
| Monthly | 1 month | Notice by 2026-12-01 |
| Weekly | 1 week | Notice by 2026-12-25 |

Steps for a raise:

1. **Check the lease type.** A fixed-term lease usually waits for renewal.
2. **Pick the start date.** Use a rent due date.
3. **Give written notice** at least one rental period before that date.
4. **Keep proof** of the delivery date.
5. **Plan for a no.** If the tenant will not accept, end a month-to-month tenancy with 30 days' written notice.

## Can an Arkansas landlord raise the rent during a fixed-term lease?

Usually not without the tenant's consent. Ark. Code 18-17-401(a) makes the rent and the term part of the rental agreement. If the lease fixes the rent for 12 months, that rent binds both sides for 12 months.

Some leases include a clause that allows a set increase during the term. If yours has one, follow its words. If not, wait for the renewal or ask the tenant to sign an amendment.

Checklist before any raise:

- [ ] Confirm the lease type and end date.
- [ ] Look for an increase clause in a fixed-term lease.
- [ ] For a periodic lease, give at least one rental period's written notice.
- [ ] Apply one rule to all tenants in the same type of unit.
- [ ] Record the reason for the new rent: market data, costs or upgrades.

The last two items matter for Fair Housing. Base each raise on the unit and the market, never on who the tenant is.

## How much notice is needed to end a month-to-month tenancy in Arkansas?

At least 30 days' written notice before the end date in the notice. Ark. Code 18-17-704(b) gives this rule to both the landlord and the tenant.

| Tenancy type | Notice | Statute |
|---|---|---|
| Month-to-month | 30 days, in writing | Ark. Code 18-17-704(b) |
| Week-to-week | 7 days, in writing | Ark. Code 18-17-704(a) |

The Attorney General's page adds that, for an oral lease, either side gives one rental period's notice. For a written lease, follow the notice terms in the lease.

If the tenant stays after the end date without consent, the landlord may sue for possession (Ark. Code 18-17-704(c)). The end of the term is a ground for eviction under Ark. Code 18-17-901(a)(2). If the holdover is a willful breach, the landlord may also recover up to 3 months' rent or twice actual damages, whichever is greater, plus attorney's fees.

## Do cities in Arkansas add their own rent or notice rules?

We found no city rent rule to report, and we could not confirm a state law that blocks one. Before you raise rent in Little Rock, Fayetteville, Fort Smith or another city, check the local code.
