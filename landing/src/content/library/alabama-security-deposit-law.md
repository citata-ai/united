Alabama puts its deposit rules in one section of the Alabama Uniform Residential Landlord and Tenant Act: Ala. Code 35-9A-201. We read the current text in the Code of Alabama on the Alabama Legislature site on 2026-10-20. The history note shows the last change came from Act 2014-279. This table holds each rule, the limit and the subsection.

| Rule | Limit or deadline | Statute |
|---|---|---|
| Maximum deposit | 1 month's periodic rent | Ala. Code 35-9A-201(a) |
| Exceptions to the cap | Pets, changes to the premises, increased liability risk | Ala. Code 35-9A-201(a) |
| Allowed deductions | Accrued rent and damage from breach of 35-9A-301 | Ala. Code 35-9A-201(b) |
| Return or itemized list | 60 days after the tenancy ends and possession is delivered | Ala. Code 35-9A-201(b), (c) |
| Tenant forwarding address | Tenant gives it in writing on move-out | Ala. Code 35-9A-201(d) |
| Unclaimed deposit | Forfeited by the tenant after 90 days | Ala. Code 35-9A-201(d) |
| Penalty for a late refund | Double the original deposit | Ala. Code 35-9A-201(f) |
| Interest or separate account | No rule in the section | Ala. Code 35-9A-201 |

## What is the maximum security deposit a landlord can charge in Alabama?

The maximum security deposit in Alabama is one month's periodic rent. Ala. Code 35-9A-201(a) says a landlord may not demand or receive security above that amount.

The cap has three exceptions. A landlord may take more for pets, for changes to the premises, or for increased liability risks to the landlord or the premises. The statute does not set a dollar limit on these extra amounts.

Worked example for a $1,200 unit:

| Charge | Amount | Within the rule? |
|---|---|---|
| Base security deposit | $1,200 | Yes, equal to 1 month's rent |
| Base security deposit | $1,500 | No, above 1 month's rent |
| Base deposit plus pet deposit | $1,200 + $300 | Yes, the pet amount is an exception |

Write the purpose of each extra amount in the lease. Then a tenant, a court and your own team can see which part is base security and which part is a pet or risk deposit.

A lease cannot waive the deposit rules. Ala. Code 35-9A-163(a)(1) says a rental agreement may not make the tenant give up the security deposit requirements of the chapter.

## How many days does an Alabama landlord have to return a security deposit?

An Alabama landlord has 60 days to return a security deposit. The clock starts when the tenancy ends and the tenant delivers possession (Ala. Code 35-9A-201(b)).

The landlord meets the rule by mailing the refund, the itemized list, or both, by first-class mail. Subsection (e) says a first-class mailing to the address the tenant gave in writing, within 60 days, is enough.

Here is how the clock works for a tenant who hands back the keys on 2026-03-31:

1. **Day 0, 2026-03-31.** The tenancy ends and the tenant delivers possession.
2. **Day 1 to 59.** You inspect, get repair quotes and write the list.
3. **Day 60, 2026-05-30.** This day is a Saturday.
4. **Deadline, 2026-06-01.** The deadline moves to Monday, the next business day.

Ala. Code 35-9A-141(3) counts days as calendar days. If the last day falls on a weekend or an official holiday, the deadline moves to the next business day when the court is open. Do not plan on the extra days: mail early.

## What can a landlord deduct from a security deposit in Alabama?

An Alabama landlord can deduct two things: accrued rent, and damages from the tenant's failure to meet Ala. Code 35-9A-301. Ala. Code 35-9A-201(b) lists only these two uses.

Ala. Code 35-9A-301 lists what a tenant must do. The tenant must:

- keep the part of the premises the tenant uses clean and safe
- remove garbage and waste in a clean and safe manner
- keep plumbing fixtures clear and use appliances in a reasonable manner
- not destroy, deface or damage the premises, or let a guest do so
- follow building and housing codes that apply to tenants

Damage outside this list is harder to deduct. The section does not use the words "normal wear and tear". But a deduction must tie to rent owed or to a breach of 35-9A-301.

## Does an Alabama landlord have to give an itemized list of deductions?

Yes. If the landlord does not refund the whole deposit, the landlord must give the tenant an itemized list of amounts withheld within the 60-day period (Ala. Code 35-9A-201(c)).

Use this checklist for each move-out:

- [ ] Write down the date the tenant delivered possession.
- [ ] Inspect the unit and take dated photos.
- [ ] List each deduction with the amount and the reason.
- [ ] Tie each damage item to a duty in Ala. Code 35-9A-301.
- [ ] Subtract the deductions and show the balance due to the tenant.
- [ ] Mail the list and the check first class by day 60.
- [ ] Keep proof of the mailing date.

The tenant has a duty too. Under Ala. Code 35-9A-201(d), the tenant must give a valid forwarding address in writing on move-out. If the tenant does not, mail the refund or list first class to the last known address. If you have none, mail it to the rental address.

A deposit or check the tenant does not claim is forfeited after 90 days (Ala. Code 35-9A-201(d)).

## Must an Alabama landlord pay interest or keep the deposit in a separate account?

No state rule requires either. Ala. Code 35-9A-201 has no rule on interest and no rule on a separate or trust account.

Subsection (h) adds a rule for a sale. Whoever holds the landlord's interest when the tenancy ends is bound by the deposit rules. If you buy a rental with tenants in place, get the deposit records and the money at closing.

## What is the penalty for an Alabama landlord who keeps a deposit wrongly?

The penalty is double the original deposit. Ala. Code 35-9A-201(f) says a landlord who fails to mail a timely refund or accounting within the 60-day period must pay the tenant double the amount of the tenant's original deposit.

Worked example: the tenant paid a $1,200 deposit. The landlord mails nothing until day 75. The tenant can claim $2,400, double the original deposit, not double the amount withheld.

Subsection (g) says the section does not stop either side from claiming other damages. So a landlord can still sue for damage above the deposit.

A second rule applies after a lockout. Under Ala. Code 35-9A-407, if the tenant ends the lease after an unlawful ouster or utility shutoff, the landlord must return all security recoverable under 35-9A-201.
