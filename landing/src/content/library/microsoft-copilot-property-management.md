## How does Microsoft Copilot find a property management company?

Microsoft Copilot finds companies through Bing search. Microsoft's own documentation explains the steps. Copilot reads the prompt and picks the terms where web data helps. Then it "generates a search query that it sends to the Bing search service" (Microsoft Learn, updated 2026-08-18).

The query is not the owner's full prompt. Microsoft says it "consists of a few words informed by the user's prompt." Copilot then uses the Bing results "to compose the response returned to the user."

So the job is simple to state. If Bing does not show your pages and listings for short queries like "property management Evanston IL", Copilot has little to quote about you.

Here is the path, step by step:

| Step | What happens | What you control |
|---|---|---|
| 1 | Owner asks Copilot for a property manager | Nothing |
| 2 | Copilot sends a short query to Bing | Words on your pages that match the query |
| 3 | Bing returns pages and listings | Bing index, Bing Places, Yelp and other listings |
| 4 | Copilot writes the answer and cites sources | Clear facts on each page: fees, cities, services |

## Does Copilot use Bing Places?

Copilot probably uses Bing Places data through Bing search, but Microsoft has not confirmed it in the documents we read. Treat the link as a hypothesis.

Here is what the sources say:

- **Bing Places feeds Bing.** Search Engine Journal reports that listings show in Bing search and Bing Maps (2025-10-03).
- **Copilot is next.** The same article says future updates may bring "deeper integrations" with Bing Maps and Copilot. That means it was not a stated feature at launch.
- **ChatGPT may read it too.** Local Falcon sells local rank tracking. It calls Bing Places one of the biggest data sources for ChatGPT local answers (2025-11-05). Local Falcon gives no data for this claim.

Bing Places is free, so a correct listing costs only time: about 1 hour (our estimate). The relaunch on October 3, 2025 moved the service to bing.com/forbusiness (PPC Land). You can import from Google Business Profile, and PPC Land reports that the import comes with "instant verification".

How to set up Bing Places:

1. **Clean your Google Business Profile first.** The import copies your name, hours and contact details from Google.
2. **Go to bing.com/forbusiness.** Sign in with a Microsoft account.
3. **Choose the Google import.** Sign in to Google and pick your locations.
4. **Check the category.** Confirm that the imported category says property management.
5. **Add your website link.** Point it to your owner page, not the tenant portal.
6. **Add photos, hours and social links.** The new Recommendation Tool suggests missing items (Search Engine Journal).

## Does Bing Webmaster Tools help?

Yes. Bing Webmaster Tools tells you if Bing can crawl and index your pages, and it now shows Copilot citations. Copilot builds web answers from Bing results, so a page that Bing does not index is unlikely to be cited.

Do these 4 things in Bing Webmaster Tools:

- [ ] Verify your domain.
- [ ] Submit your sitemap.
- [ ] Turn on IndexNow, or add it to your site. The IndexNow FAQ says one request can carry up to 10,000 URLs. All IndexNow engines get the submission: Amazon, Bing, Naver, Seznam.cz, Yandex and Yep.
- [ ] Open the AI Performance report once a month.

The AI Performance report is in public preview since February 2026. Search Influence, an agency that studied its own data, says it has 3 exports: daily citations, page-level stats and grounding queries (2026). Grounding queries are the short queries Copilot sent to Bing. The report has no API and no click data yet.

Search Influence also shows how uneven citations can be. Over 91 days, one page got 13,599 of its 19,717 citations, about 69% (Search Influence, 2026). One page can carry your whole Copilot presence. Find that page and keep it current.

## Which review sites does Bing show?

Bing shows reviews from other sites, not only its own. BrightLocal named Yelp, TripAdvisor and Facebook as review sources in Bing local results (BrightLocal, 2020-06-17). That article is old, so check your own Bing listing today.

How to check:

1. Search your company name on bing.com.
2. Open the local panel on the right.
3. Write down each review source and its star count.
4. Fix or claim each source that shows wrong facts.

For property managers, Yelp matters in other engines too. We asked "What is the best property management company in [city]?" and got 150 answers. Yelp was a source in 50 of them and Expertise.com in 93 (our data, 2026-10-19). That test covered ChatGPT, Claude and Gemini. We did not test Copilot.

## How do you test Copilot answers?

Test Copilot with fixed owner prompts once a month, and read the sources under each answer. Microsoft says Copilot Chat shows the exact web search queries it sent to Bing in the citation section. Microsoft also says those queries stay in the chat thread for only 24 hours. Save them the same day.

Use this test sheet:

| Prompt | Named? | Rank | Your page cited? | Bing query shown |
|---|---|---|---|---|
| "Best property management company in [city]" |  |  |  |  |
| "Property manager for a single-family rental in [city]" |  |  |  |  |
| "How much does property management cost in [city]?" |  |  |  |  |
| "Is [your company] a good property manager?" |  |  |  |  |
| "Property manager that accepts Section 8 in [city]" |  |  |  |  |

Run each prompt 2 times, logged out or in a private window. That is 10 answers a month. Then search the Bing query from the citation section on bing.com. The pages Bing ranks for that query are the pages Copilot reads.

Watch for: an answer that names you but cites only a directory. That means Bing trusts the directory more than your page. Add the missing fact, such as your fee or your city list, to your own page in plain words.

## What should you do first?

Start with the 3 tasks that take one afternoon:

1. **Claim Bing Places.** Import from Google, then fix the category and link.
2. **Verify your site in Bing Webmaster Tools.** Submit the sitemap and turn on IndexNow.
3. **Run the 5 test prompts in Copilot.** Save the answers and the Bing queries.

Then repeat the test in 30 days. Copilot answers change, so compare month to month, not day to day.
