## Which costs do you include?

Include every software and service charge required to run the proposed workflow. Start with invoices and signed terms rather than a vendor's smallest advertised price. Separate costs that recur from costs tied to the move.

Use this worksheet:

| Cost group | Inputs to collect |
|---|---|
| Base software | Plan price, minimum and billable units |
| Specialist tools | Leasing, maintenance, CRM and inspections |
| Usage | Payments, messages, signatures and screenings |
| Connections | Integration, API or automation service charges |
| Setup | Migration, training and configuration |
| Support | Paid support or required service packages |
| Exit | Export assistance or overlapping subscriptions |

Vendor pages show why the categories matter. Buildium lists transaction and document charges. Rentvine describes a setup fee and possible transaction charges. Property Meld lists a separate On-Call add-on.

Keep staff time outside the cash subscription total, but show it beside the result. A tool with a lower invoice can still need more internal work.

## How do you count payment-processing fees?

Multiply each payment type by its fee, then assign the charge to the person who pays it. Keep bank transfers, cards, outgoing payments and returned payments separate. Their fee bases can differ.

For a flat charge, use transaction count times fee. For a percentage charge, use payment value times rate. Check for a minimum, maximum or plan condition before calculating.

Buildium's reviewed pricing page, for example, lists different incoming EFT charges by plan. This means comparing plan subscriptions alone can miss a material cost. Use the selected plan's actual fee schedule rather than a general statement about online payments.

Count only company-absorbed fees in business cost per door. Show owner-, renter- and applicant-paid fees in separate columns. Do not hide those costs simply because your company does not pay them. Ask the vendor to resolve unclear payer or timing rules.

## What is a normal cost per door?

A useful cost per door is a consistent measure of your own setup, not an unsupported industry average. We have not verified a representative benchmark for the full property-management software stack. Different definitions produce different results.

Use a stable denominator. Decide whether “doors” means all managed units or only occupied units. Then apply the same definition to every option. A vendor's billable-unit definition can differ from your internal measure.

Use this formula for cash cost:

> Monthly cost per managed door = total monthly company-paid software cost ÷ managed doors.

Add allocated setup only if you label the allocation period. Show the recurring-only result beside it. This prevents a large migration bill from looking like a permanent subscription increase.

Track the metric over time with the same scope. If you add a service that staff previously performed manually, explain that change before comparing the new total with the old one.

## What does a worked calculation look like?

The following calculation uses invented planning inputs, not vendor quotes or a market benchmark. Every amount in this example is a stated assumption. Replace the inputs with your own invoices and dated offers.

| Hypothetical monthly input | Stack A | Stack B |
|---|---|---|
| Base plan | $300 | $450 |
| Specialist tools | $200 | $100 |
| Company-paid usage | $50 | $25 |
| Setup allocated over 12 months | $100 | $50 |
| Total | $650 | $625 |
| Managed doors, assumed | 100 | 100 |
| Cost per door | $6.50 | $6.25 |

Example arithmetic: Stack A is $300 + $200 + $50 + $100 = $650. Divide by 100 assumed doors to get $6.50. Stack B uses the same method.

The difference does not prove Stack B is better. Check whether both stacks complete the same work. If Stack B excludes a required repair service, add that cost before comparing.

## Which costs can you pass to owners or tenants?

Do not assume you can pass a charge through merely because software supports the setting. Review the management agreement, lease, disclosure and applicable law for the actual charge. This article does not state a universal fee rule.

Keep authority separate from accounting. A recoverable business cost should still appear in the full service-cost view. Record who pays, how the fee is disclosed and how staff explain it.

Ask the vendor to show a sample receipt and owner statement. Check whether the charge appears under the intended label. Avoid using a vague category that hides the service or payer.

Have counsel review new pass-through fees before launch. This is general information, not legal advice. Check the current law or ask a local attorney. Use the worksheet to make costs visible, not to justify an unreviewed fee.

## How do you compare two stacks fairly?

Compare identical work, counts and time periods. A lower plan price means little if another product supplies a service the cheaper option excludes. Define required functions before collecting quotes.

- **Scope:** list the work every option must complete.
- **Volume:** use the same doors, payments, messages and documents.
- **Term:** compare equivalent commitment and billing periods.
- **Setup:** show cash due and the chosen allocation separately.
- **Unknowns:** mark missing prices as unresolved.
- **Labor:** estimate internal work outside the subscription total.
- **Exit:** include required overlap and export assistance.

Ask each vendor to confirm the inputs in writing. Recalculate after the first real bill and investigate differences. Keep optional tools out until you decide they solve a defined need.
