## West Virginia rent and notice rules at a glance

West Virginia keeps its rent rules simple. The main statute is W. Va. Code 37-6-5, on notice to end a tenancy. We read it, and the related sections below, on the West Virginia Legislature's code site on 2026-10-19.

| Rule | Limit or deadline | Statute |
|---|---|---|
| Statewide rent cap | None in the sections we read | Chapter 37, articles 6 and 6A |
| Rent increase notice | No set number of days in the sections we read | Chapter 37, article 6 |
| Increase during a fixed term | Only if the lease allows it | The lease |
| End a month-to-month tenancy | Notice for one full period before the end of a period | W. Va. Code 37-6-5 |
| End a year-to-year tenancy | Written notice at least 3 months before the year ends | W. Va. Code 37-6-5 |
| Lease with a set end date | No notice needed | W. Va. Code 37-6-5 |
| Lease sets another notice period | The lease controls | W. Va. Code 37-6-5 |
| Tenant stays after the right ends | Summary petition or unlawful detainer | W. Va. Code 55-3A-1, 55-3-1 |

This is general information, not legal advice. Check the current law or ask a local attorney.

## Does West Virginia have a cap on rent increases or rent control?

The West Virginia Code sections we read set no cap on rent increases. Article 6 of chapter 37 (landlord and tenant) and article 6A (security deposits) do not limit how much a landlord may charge or raise rent.

So the amount of a West Virginia rent increase is a market and lease question. Two limits still apply:

- **The lease.** A fixed-term lease sets the rent for the term.
- **Local rules.** We did not review every city code. Check the code of the city where the unit is before you act.

What counts as rent matters. W. Va. Code 37-6A-1(11) defines rent as all money owed under the rental agreement other than a security deposit, a nonrefundable fee or a payment for damage. If you add a recurring fee, treat it as part of the rent change and give the same notice.

## How many days notice does a West Virginia landlord need to raise the rent?

No section we read sets a number of days for a West Virginia rent increase notice. The law gives you a different tool: the notice to end a periodic tenancy in W. Va. Code 37-6-5.

For a month-to-month tenancy, a rent change is in effect a change of terms. The safe path is to give the tenant at least the notice that would end the tenancy. Under 37-6-5, that is notice for one full period before the end of a period. Put it in writing and state:

1. The current rent.
2. The new rent and the first rental period it applies to.
3. The date of the notice.

**Worked example.** Rent is $1,100, due on the first of each month. You want $1,175 from June 1. Deliver the written notice on or before April 30. That gives one full rental period (May 1 to May 31) before the new rent starts on June 1. If you deliver it on May 3, the first full period is June, so start the new rent on July 1.

| Notice delivered | First full period after notice | New rent starts |
|---|---|---|
| April 30 | May 1-31 | June 1 |
| May 3 | June 1-30 | July 1 |
| May 31 | June 1-30 | July 1 |

Read your lease first. If it sets a longer notice for rent changes, follow the lease.

## Can a West Virginia landlord raise the rent during a fixed-term lease?

A West Virginia landlord may raise rent during a fixed-term lease only if the lease allows it. A lease for a set term fixes the rent for that term. We found no statute that lets a landlord change it mid-term without the tenant's agreement.

If you want room to raise rent, write it into the lease:

- **Escalation clause.** A set increase on a set date, such as 3% after month 12.
- **Renewal terms.** New rent stated in the renewal offer.

At the end of a fixed term, no notice is needed to end the tenancy (W. Va. Code 37-6-5). Offer the renewal at the new rent well before the end date, so the tenant can decide.

## How much notice is needed to end a month-to-month tenancy in West Virginia?

A West Virginia month-to-month tenancy ends with notice for one full period before the end of any period. W. Va. Code 37-6-5 says a periodic tenancy of less than a year may end "by like notice, or by notice for one full period before the end of any period." Either the landlord or the tenant may give it.

| Tenancy type | Notice to end | Statute |
|---|---|---|
| Week-to-week | One full week before the end of a week | W. Va. Code 37-6-5 |
| Month-to-month | One full month before the end of a month | W. Va. Code 37-6-5 |
| Year-to-year | Written, at least 3 months before the end of the year | W. Va. Code 37-6-5 |
| Fixed term with a set end date | None | W. Va. Code 37-6-5 |

How to serve it:

- **Landlord to tenant.** Serve the tenant, or anyone holding the unit under the tenant.
- **Tenant to landlord.** Serve anyone who owns the property in whole or in part, or the owner's agent.

The lease can change these rules. 37-6-5 does not apply where a special agreement fixes another notice period, or says no notice is to be given.

If the tenant stays after a valid notice, you may file to recover possession. W. Va. Code 55-3A-1 gives a summary petition for rent arrears, breach or damage. W. Va. Code 55-3-1 covers a tenant who holds over after the right to possession expired.

## Do cities in West Virginia add their own rent or notice rules?

We did not find a city rent rule in the sources we read, and we did not review every city code. A West Virginia city may have a rental registration, inspection or housing code program. Those programs can affect your notices and repairs. Check the municipal code where the unit is.

The state habitability duty applies everywhere. W. Va. Code 37-6-30 requires the landlord to deliver and keep the unit fit and habitable. Reasonable heat is due from October 1 to the last day of April. Running water and reasonable hot water are due at all times on direct public utility connections. A rent increase does not change those duties.

## West Virginia rent increase checklist

- [ ] Lease type confirmed: fixed term, month-to-month or year-to-year.
- [ ] Fixed term: increase only at renewal or under a written escalation clause.
- [ ] Month-to-month: written notice delivered before one full rental period.
- [ ] Year-to-year: written notice at least 3 months before the year ends.
- [ ] Lease checked for a longer notice period.
- [ ] City code checked for local rental rules.
- [ ] New recurring fees counted as part of the rent change.
