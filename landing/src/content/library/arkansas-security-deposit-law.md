Arkansas deposit rules fill six short sections: Ark. Code 18-16-301 to 18-16-306. The official code site did not load for us, so we read the statute text on FindLaw, which quotes the code current as of 2024-03-28. The Arkansas Attorney General's landlord-tenant page states the same cap and deadline. Check for any 2025 or later act before you rely on these rules.

| Rule | Limit or deadline | Statute |
|---|---|---|
| Who is covered | Owners of 6 or more units, or any unit run by a paid manager | Ark. Code 18-16-303 |
| Maximum deposit | 2 months' periodic rent | Ark. Code 18-16-304 |
| Return deadline | 60 days after the tenancy ends | Ark. Code 18-16-305(a) |
| Allowed deductions | Unpaid rent and damage from breach of the rental agreement | Ark. Code 18-16-305(a)(2) |
| Itemized notice | Required with any balance | Ark. Code 18-16-305(a)(2) |
| How to send it | First-class mail to the last known address | Ark. Code 18-16-305(b) |
| Returned, unclaimed refund | Landlord's after 180 days | Ark. Code 18-16-305(b)(2) |
| Penalty | 2 times the amount wrongfully withheld, plus costs and fees | Ark. Code 18-16-306 |
| Interest or separate account | No rule in the subchapter | Ark. Code 18-16-301 to 306 |

## Who does the Arkansas security deposit law cover?

The law covers most professional landlords but not the smallest owners. Ark. Code 18-16-303(a) exempts units owned by an individual when that person, a spouse, minor children and their rental entities own 5 or fewer units in total.

The exemption ends when a manager is paid. Subsection (b) says it does not apply to units where a third person manages the units, including rent collection, for a fee.

| Owner | Units | Paid manager? | Deposit law applies? |
|---|---|---|---|
| Individual | 4 | No | No |
| Individual | 4 | Yes | Yes |
| Individual and spouse, through an LLC | 8 | No | Yes |

This matters to property management companies. If you manage for a fee, the deposit rules apply to every unit you manage, even for a 1-unit owner.

## What is the maximum security deposit a landlord can charge in Arkansas?

The maximum is 2 months' periodic rent. Ark. Code 18-16-304 says a landlord may not demand or receive a security deposit, "however denominated", above that amount.

Worked example:

| Monthly rent | Maximum deposit |
|---|---|
| $900 | $1,800 |
| $1,250 | $2,500 |
| $1,800 | $3,600 |

The name of the charge does not change the cap. A refundable "pet deposit" or "cleaning deposit" counts toward the total.

## How many days does an Arkansas landlord have to return a security deposit?

An Arkansas landlord has 60 days. Ark. Code 18-16-305(a)(1) says the deposit must be returned within 60 days of the end of the tenancy.

The landlord meets the rule by mailing the notice and any payment by first-class mail to the tenant's last known address (Ark. Code 18-16-305(b)(1)). Get a forwarding address at move-out to make this easy.

If the letter comes back and you cannot find the tenant after a reasonable effort, the payment becomes yours 180 days after the mailing date (Ark. Code 18-16-305(b)(2)).

Timeline for a tenancy that ends on 2026-06-30:

1. **2026-06-30.** The tenancy ends and the tenant returns the keys.
2. **Within days.** Inspect the unit and take dated photos.
3. **By 2026-08-29.** Mail the itemized notice and the balance.

## What can a landlord deduct from a security deposit in Arkansas?

An Arkansas landlord may deduct accrued unpaid rent and damages caused by the tenant's breach of the rental agreement. Ark. Code 18-16-305(a)(2) lists these two uses.

The tie to the rental agreement matters. Write clear tenant duties in the lease, such as cleaning, yard care and damage rules. A deduction is easier to defend when it points to a lease term.

If damages or unpaid rent exceed the deposit, the Arkansas Attorney General's page says the landlord may keep the whole deposit. You can still claim the rest in court.

## Does an Arkansas landlord have to give an itemized list of deductions?

Yes. Ark. Code 18-16-305(a)(2) says deductions must be "itemized by the landlord in a written notice delivered to the tenant", with the rest of the amount due.

Move-out checklist:

- [ ] Confirm the unit is covered (6 or more units, or a paid manager).
- [ ] Record the date the tenancy ended.
- [ ] Inspect and take dated photos.
- [ ] List each deduction with the amount and the lease term it ties to.
- [ ] Show the balance due to the tenant.
- [ ] Mail the notice and check first class within 60 days.
- [ ] Keep proof of the mailing date.

## Must an Arkansas landlord pay interest or keep the deposit in a separate account?

No rule requires either. Ark. Code 18-16-301 to 18-16-306 has no interest rule and no separate account rule.

One rule covers a sale. Under Ark. Code 18-16-302, whoever holds the landlord's interest when the tenancy ends is bound by the subchapter. If you buy a rental, take over the deposits at closing.

If you hire a manager, your agreement should say where the manager holds deposits. Our guide on [how owners choose a property manager](/guides/how-owners-choose-a-property-manager-with-ai) lists the questions to ask.

## What is the penalty for an Arkansas landlord who keeps a deposit wrongly?

The penalty is twice the amount wrongfully withheld, plus the money due, costs and reasonable attorney's fees. Ark. Code 18-16-306(a)(1) gives the tenant these claims.

Worked example: a landlord wrongfully keeps $1,000. The tenant may recover the $1,000, plus $2,000 in damages, plus costs and attorney's fees.

The statute has a defense. Under Ark. Code 18-16-306(a)(2), the landlord owes only costs and the sum wrongly kept if it proves either:

- an error despite procedures reasonably designed to avoid errors, or
- a good-faith dispute about the amount due.
