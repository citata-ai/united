## West Virginia eviction rules at a glance

West Virginia has a fast, summary eviction process for residential rentals in article 3A of chapter 55 of the Code. We read each section on the West Virginia Legislature's code site on 2026-10-19.

| Step or rule | Limit or deadline | Statute |
|---|---|---|
| Grounds | Rent arrears, breach of a lease covenant, or damage to the property | W. Va. Code 55-3A-1(a)(3) |
| Pre-filing notice for rent | None set in the summary statute | W. Va. Code 55-3A-1 |
| Court | Magistrate or circuit court of the county | W. Va. Code 55-3A-1(a) |
| Petition | Verified, with the arrears or breach described | W. Va. Code 55-3A-1(a) |
| Hearing date | 5 to 10 judicial days after filing | W. Va. Code 55-3A-1(b) |
| Service | Rule 4 service or certified mail, return receipt | W. Va. Code 55-3A-1(c) |
| Tenant's written defense | Within 5 days of receiving notice | W. Va. Code 55-3A-1(c) |
| Continuance | For cause only; tenant pays rent into court | W. Va. Code 55-3A-3(d) |
| Removal | Sheriff, after the vacate date in the order | W. Va. Code 55-3A-3(f) |
| Property left behind | Dispose after 30 days in most cases | W. Va. Code 55-3A-3(h) |
| End a month-to-month tenancy | One full period's notice | W. Va. Code 37-6-5 |

This is general information, not legal advice. Check the current law or ask a local attorney.

## What notice must a West Virginia landlord give before filing an eviction for unpaid rent?

The summary eviction statute sets no pre-filing notice period for unpaid rent. W. Va. Code 55-3A-1(a) lets an owner or agent file a verified petition when the tenant "is in arrears in the payment of rent." The petition must describe the arrearage.

Two other rules can add a notice step:

- **The lease.** If your lease promises a notice or a grace period before you file, follow it.
- **End of a periodic tenancy.** To end a month-to-month tenancy without a breach, give notice for one full period before the end of a period (W. Va. Code 37-6-5). A year-to-year tenancy needs written notice at least 3 months before the year ends.

A written demand for rent before you file is still a good practice. It creates a record for the petition. It is not a statutory step in article 3A.

## How long does an eviction take in West Virginia?

A West Virginia summary eviction can reach a hearing within 5 to 10 judicial days of filing. W. Va. Code 55-3A-1(b) tells the court to set the hearing in that window. Judicial days are court business days, so weekends and court holidays do not count.

| Phase | Time | Statute |
|---|---|---|
| File the verified petition | Day 0 | 55-3A-1(a) |
| Serve notice of the hearing | At once, by Rule 4 or certified mail | 55-3A-1(c) |
| Tenant's written defense | Within 5 days of the tenant's receipt | 55-3A-1(c) |
| Hearing | 5 to 10 judicial days after filing | 55-3A-1(b) |
| Order to vacate | Date set by the court | 55-3A-3(f) |
| Sheriff removal | After the vacate date | 55-3A-3(f) |

The court sets the vacate date by looking at the facts. It considers whether the unit is furnished, the relative harm to each side and other relevant facts (W. Va. Code 55-3A-3(f)). So the time from hearing to move-out varies.

Continuances are limited. The judge or magistrate grants one for cause only, never as a right. If the tenant asks for one, the tenant must pay into court any rent that comes due during it (W. Va. Code 55-3A-3(d)).

An appeal does not let a tenant stay past the end of the lease term. W. Va. Code 55-3A-3(g) says the tenant is not entitled to stay in possession during an appeal if the tenancy has otherwise expired.

## Where does a landlord file an eviction case in West Virginia, and what does it cost?

A West Virginia landlord files in the magistrate court or the circuit court of the county where the property is (W. Va. Code 55-3A-1(a)). The petition must state:

1. That you are the owner or the owner's agent with a right to possession.
2. A short description of the property.
3. How the tenant is wrongfully in possession: rent arrears, a breach of a warranty or covenant, or damage. Describe the facts.
4. A request for possession.

After the court sets the hearing, serve the tenant with notice. Use Rule 4 of the West Virginia Rules of Civil Procedure or certified mail, return receipt requested. Then file the petition and the proof of service with the court (W. Va. Code 55-3A-1(c)).

Magistrate court costs come from W. Va. Code 50-3-1. For a civil action that seeks relief other than money damages, the listed cost is $30. When you also claim rent, the cost depends on the amount claimed:

| Amount claimed | Listed cost |
|---|---|
| $500 or less | $30 |
| $500.01 to $1,000 | $35 |
| $1,000.01 to $2,000 | $40 |
| More than $2,000 | $50 |
| Relief other than money damages | $30 |

The section also lists other charges, such as certified mail and enforcement services. Ask the magistrate clerk for the total before you file. Circuit court fees are different.

## Can a West Virginia landlord evict a tenant for a lease violation or with no cause?

A West Virginia landlord may use the summary process for a lease violation. W. Va. Code 55-3A-1(a)(3) covers a tenant who "has breached a warranty or a leasehold covenant." It also covers one who has deliberately or negligently damaged the property or let another person do so.

The tenant may raise any defense that applies in an ejectment or unlawful detainer action (W. Va. Code 55-3A-2). For a rent case, the tenant may claim that the landlord broke a material covenant on which the duty to pay rent depends. One example is the duty to keep the unit fit and habitable under W. Va. Code 37-6-30. If the tenant raises it, the court holds a hearing on that issue (W. Va. Code 55-3A-3(b)).

For no cause, the statute gives no summary route. Instead, end the tenancy with proper notice. Under W. Va. Code 37-6-5, a month-to-month tenancy ends with notice for one full period before the end of a period. A tenancy with a set end date needs no notice. If the tenant then stays, you may sue for possession. W. Va. Code 55-3-1 allows an unlawful detainer action against a tenant who holds over after the right to possession has expired.

## Who removes the tenant after a judgment in West Virginia?

The sheriff removes the tenant. The court order must set the time to vacate. It must also say that if the tenant stays past that time, "the sheriff shall forthwith remove the tenant," with care to avoid damage to both sides' property (W. Va. Code 55-3A-3(f)).

For property the tenant leaves behind after the vacate date, W. Va. Code 55-3A-3(h) gives three choices:

1. **Dispose at once.** Only if the tenant says in writing that it is abandoned, or it is garbage.
2. **Remove and store.** Dispose after 30 days if the tenant has not paid storage costs and taken the property, or if storage costs equal its value.
3. **Leave it in place.** Dispose after 30 days if the tenant has not paid the costs and taken it.

If the property is worth more than $300, a tenant or secured lender may say they intend to remove it. Then you must store it up to 30 more days, if they pay the reasonable costs (W. Va. Code 55-3A-3(i)).

## Is a self-help eviction (lockout, utility shutoff) legal in West Virginia?

The West Virginia summary eviction statute gives the sheriff, not the landlord, the job of removal. The sheriff acts under a court order (W. Va. Code 55-3A-3(f)). The sections we read do not authorize a landlord to change locks or cut utilities to force a tenant out. Do not use self-help.

The Code also requires the landlord to keep up utility service. W. Va. Code 37-6-30(a)(7) requires running water and reasonable hot water at all times for units on direct public utility connections. It also requires reasonable heat from October 1 to the last day of April. A shutoff can break that duty and give the tenant a defense under 55-3A-3(b).

One narrow rule covers abandonment. If a tenant who owes rent abandons the unit, you may post a written notice on the property to pay within one month. If the rent is not paid, you are entitled to possession (W. Va. Code 37-6-6).

## West Virginia eviction checklist for landlords

- [ ] Confirm the ground: arrears, breach or damage, and write the facts.
- [ ] Check the lease for any notice or grace period you promised.
- [ ] File a verified petition in magistrate or circuit court of the county.
- [ ] Serve the hearing notice by Rule 4 or certified mail, then file proof of service.
- [ ] Bring the lease, ledger, photos and notices to the hearing.
- [ ] After the order, let the sheriff remove the tenant.
- [ ] Track the 30-day property windows.
