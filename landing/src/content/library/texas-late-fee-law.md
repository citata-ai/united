## Texas late fee rules at a glance

Texas late fee law sits in one section: Property Code 92.019. The Legislature last amended that section with SB 1414 in 2019, effective September 1, 2019. The table sums up the rules.

| Rule | Limit or deadline | Statute |
|---|---|---|
| Notice of the fee | Must be in a written lease | Prop. Code 92.019(a)(1) |
| Grace period | Rent unpaid 2 full days after the due date | Prop. Code 92.019(a)(3) |
| Safe cap, 1 to 4 units in the structure | 12% of the rent for the rental period | Prop. Code 92.019(a-1)(1)(A) |
| Safe cap, more than 4 units in the structure | 10% of the rent for the rental period | Prop. Code 92.019(a-1)(1)(B) |
| Fee above the safe cap | Only up to the landlord's uncertain damages | Prop. Code 92.019(a-1)(2) |
| Daily fee | Allowed; initial plus daily counts as 1 fee | Prop. Code 92.019(b) |
| Penalty | $100 + 3 times the fee + attorney's fees | Prop. Code 92.019(c) |
| Lease waiver | Void | Prop. Code 92.019(d) |
| Tenant asks for a late fee statement | Landlord must answer in writing | Prop. Code 92.0191 |

## What is the maximum late fee a Texas landlord can charge?

Texas sets a safe cap, not a hard cap. Property Code 92.019(a-1) says a late fee is "considered reasonable" if it is not more than:

- **12% of the rent** for the rental period, for a dwelling in a structure with 4 or fewer units.
- **10% of the rent** for the rental period, for a dwelling in a structure with more than 4 units.

A fee above that line is still reasonable only if it is "not more than uncertain damages" to the landlord from the late payment. The statute names direct or indirect expenses, costs and overhead of collecting late rent. A fee above the safe cap invites a dispute about those costs. A fee at or under the cap is presumed reasonable.

Here is the math for 3 common cases:

| Unit | Monthly rent | Units in the building | Safe cap rate | Maximum safe late fee |
|---|---|---|---|---|
| Duplex side | $1,400 | 2 | 12% | $168 |
| Fourplex unit | $1,200 | 4 | 12% | $144 |
| Apartment | $1,500 | 120 | 10% | $150 |

The cap counts units in the structure, not in your portfolio. A landlord with 40 single-family homes uses 12% for each home. A landlord with one 6-unit building uses 10%.

## Does Texas law require a grace period before a late fee?

Yes. Texas requires 2 full days. Property Code 92.019(a)(3) sets the wait. Some part of the rent must remain "unpaid two full days after the date the rent was originally due."

With rent due on the 1st, the 2nd and the 3rd are the 2 full days. So the earliest day a fee can apply is the 4th. The rule covers any unpaid part of the rent, not only the full amount.

A lease can give a longer grace period. A lease cannot give a shorter one, because 92.019(d) voids any waiver.

## Must the late fee be written in the Texas lease?

Yes. Property Code 92.019(a)(1) requires notice of the fee in a written lease. An oral agreement or a sign in the office is not enough.

Use this checklist when you write the late fee clause:

- [ ] The lease names the fee amount or the formula.
- [ ] The total, with any daily fee, stays at or under 12% or 10% of the rent.
- [ ] The fee starts only after 2 full days late (for rent due on the 1st, on the 4th).
- [ ] The clause says if the fee has an initial part and a daily part.
- [ ] Your rent software uses the same start date and cap as the lease.
- [ ] Staff know how to answer a tenant's written request for a late fee statement (92.0191).

The last item is easy to miss. Under 92.0191, a tenant may ask if a late fee is owed and how much. You must answer by the means you normally use to write to the tenant. If you do not answer, the tenant still owes a valid fee.

## Can a Texas landlord charge a daily late fee?

Yes. Property Code 92.019(b) allows "an initial fee and a daily fee for each day any portion of the tenant's rent continues to remain unpaid." The combined fees count as a single late fee. So the total must stay reasonable.

Worked example. Rent is $1,500 in a 120-unit building, so the safe cap is 10%, or $150.

| Day of the month | Fee that day | Running total |
|---|---|---|
| 1st to 3rd | $0 (grace period) | $0 |
| 4th | $50 initial fee | $50 |
| 5th to 14th | $10 a day for 10 days | $150 |
| 15th onward | $0, cap reached | $150 |

A daily fee that runs all month would pass the cap. Set your software to stop the daily fee at the cap.

## What is the penalty for an illegal late fee in Texas?

A Texas landlord who violates 92.019 owes the tenant 3 amounts (92.019(c)):

1. **$100.**
2. **3 times the late fee** collected in violation of the section.
3. **The tenant's reasonable attorney's fees.**

Example: a landlord collects a $200 late fee on $1,500 rent in a large complex. The safe cap is $150. If a court finds the fee unreasonable, the landlord owes $100 + 3 × $200 = $700, plus the tenant's lawyer's fees. If the tenant pays the fee, the tenant does not lose these rights (92.019(e)).

## Can a Texas landlord evict a tenant for unpaid late fees?

Section 92.019 does not stop a lawful eviction. Under 92.019(e), the late fee rules do not affect your right to end the lease or take other action that the lease or the law allows.

Be careful with the notice. Since January 1, 2026, Property Code 24.005(a) sets a special rule for a case based "solely on nonpayment of rent." If the tenant was not late before that month, the notice must be a notice to pay rent or vacate. Whether a late fee counts as rent depends on your lease. Ask your attorney before you file a case for fees alone.
