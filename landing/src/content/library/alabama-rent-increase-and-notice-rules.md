Alabama has few rules on rent increases. That is the main finding when you read the code. We read each section below in the Code of Alabama on the Alabama Legislature site on 2026-10-20. The table shows what the law sets and where it is silent.

| Rule | Limit or deadline | Statute |
|---|---|---|
| Statewide cap on increases | None in the landlord-tenant act | Ala. Code 35-9A |
| Local rent control | Banned for counties and cities | Ala. Code 11-80-8.1 |
| Notice of a rent increase | No section sets one | Ala. Code 35-9A |
| End a month-to-month tenancy | 30 days before the periodic rental date | Ala. Code 35-9A-441(b) |
| End a week-to-week tenancy | 7 days | Ala. Code 35-9A-441(a) |
| Rent during a fixed term | Set by the rental agreement | Ala. Code 35-9A-161(a) |
| Retaliatory increase | Not allowed | Ala. Code 35-9A-501 |

## Does Alabama have a cap on rent increases or rent control?

No. Alabama has no rent cap and no rent control. The Alabama Uniform Residential Landlord and Tenant Act (Ala. Code 35-9A) does not limit how much rent may rise.

A second law closes the door for cities. Ala. Code 11-80-8.1(b) says a local government may not enact, maintain or enforce an ordinance, resolution or rule that would control the rent charged for private property. The section has been in the code since 1993 (Act 93-421).

The ban covers private property only. Subsection (b) keeps the right of a local government to manage property in which it has an interest.

## How many days notice does an Alabama landlord need to raise the rent?

The Alabama act has no section that sets a notice period for a rent increase. We searched the act for an increase notice rule and found none.

The notice to end a tenancy sets the practical floor. For a month-to-month tenancy, Ala. Code 35-9A-441(b) lets either side end the tenancy with written notice at least 30 days before the periodic rental date in the notice. A landlord who wants new terms can end the old tenancy on that notice. So give at least 30 days' written notice before the rental date, and more when you can.

Worked example for a tenant who pays on the 1st:

1. **Decide the new rent** and the start date, 2026-12-01.
2. **Count back 30 days.** The notice must reach the tenant by 2026-11-01.
3. **Send it in writing.** Keep a copy and proof of delivery.
4. **Plan for a no.** If the tenant will not pay the new rent, the tenancy ends on the rental date in the notice.

For a week-to-week tenancy, the same logic uses 7 days' written notice (Ala. Code 35-9A-441(a)).

Ala. Code 35-9A-141(3) counts days as calendar days. If the last day of a period falls on a weekend or an official holiday, it moves to the next business day.

## Can an Alabama landlord raise the rent during a fixed-term lease?

Usually not without the tenant's consent. Ala. Code 35-9A-161(a) makes rent and the term of the agreement part of the rental agreement. If the lease fixes the rent for 12 months, that rent binds both sides for 12 months.

Some leases include a clause that allows a set increase during the term. If your lease has one, follow its words. If it does not, wait for the renewal or ask the tenant to sign an amendment.

Use this checklist before any raise:

- [ ] Check the lease type: fixed term or month-to-month.
- [ ] For a fixed term, check for an increase clause.
- [ ] For month-to-month, give written notice at least 30 days before the rental date.
- [ ] Check that the raise does not follow a tenant complaint (see below).
- [ ] Apply the same rule to every tenant in the same type of unit.

The last item matters for Fair Housing. Base each raise on the unit and the market, never on who the tenant is.

## How much notice is needed to end a month-to-month tenancy in Alabama?

At least 30 days' written notice before the periodic rental date named in the notice. Ala. Code 35-9A-441(b) gives this rule to both the landlord and the tenant.

| Tenancy type | Notice | Statute |
|---|---|---|
| Month-to-month | 30 days before the periodic rental date | Ala. Code 35-9A-441(b) |
| Week-to-week | 7 days before the termination date | Ala. Code 35-9A-441(a) |
| No written term | Week-to-week if rent is weekly, else month-to-month | Ala. Code 35-9A-161(d) |

The notice must be in writing. Use a delivery method you can prove.

If the tenant stays past the end date without your consent, you may file for possession. If the holdover is willful and not in good faith, you may also claim up to 3 months' rent or actual damages, whichever is greater, plus attorney's fees (Ala. Code 35-9A-441(c)).

## Do cities in Alabama add their own rent or notice rules?

Not on the amount of rent. Ala. Code 11-80-8.1 bars every county, city, town and other local government from controlling private rents. So Birmingham, Montgomery, Mobile and Huntsville cannot pass rent control.

The state act still limits one kind of increase. Ala. Code 35-9A-501(a) says a landlord may not retaliate by a discriminatory rent increase because the tenant:

- complained to a building or housing code agency about a health or safety problem
- complained to the landlord about a repair duty under Ala. Code 35-9A-204
- organized or joined a tenant union

A tenant who proves retaliation gets the remedies in Ala. Code 35-9A-407 and a defense to an eviction. Those remedies include up to 3 months' rent or actual damages, whichever is greater.
