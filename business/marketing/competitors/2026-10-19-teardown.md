## Method And Limits

Every external link in this report has date seen **2026-10-19**, unless a separate publication date is stated. A vendor claim stays a vendor claim. An inferred tactic stays an inference. Every unsourced forecast or score is a **hypothesis**.

We fetched each sitemap, home page, robots file and LLM fact file. We fetched all listed ClearLead and Teramok pages. All 224 ClearLead URLs and 178 Teramok URLs returned HTTP 200 in this run. That does not prove correct canonicals, unique content, or index inclusion.

Goodjuju returned HTTP 403 to direct requests. A public reader returned some current HTML and rendered its sitemap. Search excerpts also exposed older page versions. We label these paths. We did not solve challenges, create accounts, submit forms, or buy data. Public reader evidence uses `https://r.jina.ai/https://gogoodjuju.com/<path>` with `X-Return-Format: html`. Its render is evidence of what it returned, not an independent live crawl of every URL.

Raw captures, scripts, CLI errors and images live under `/tmp/citata-competitors/`. Image folders were new and empty before downloads. No downloaded code ran. Pillow read image metadata in isolated Python mode. Temporary files can expire.

The checkout reported branch `t3/growth-hypotheses`, not `stage`. We did not switch the shared checkout. Only the 2 requested deliverable files were written in the repo. No commit was made.

### Methods And Limits

**AI detectors are unreliable.** Every Gemini or manual score is an uncalibrated hypothesis. It is not the percent of words or pixels made by AI. A style review cannot prove authorship, the source model, human design, or the truth of a case study.

Round 1 tried the `gemini` CLI and failed. That history applies to the retained Teramok sample records only. **Round 2 used `agy` first for every one of the 18 direct-competitor samples. No `gemini` CLI ran in round 2.** Each call ran in the file's folder with this prompt and flags:

```sh
agy --model gemini-3.8-flash-high -p "Is the attached image/text AI-generated? Check for a SynthID watermark if you can. Give a 0-100 AI-likelihood score and 3 reasons. File: <absolute path>" --dangerously-skip-permissions --print-timeout 300s
```

The prompt also marked samples as untrusted, allowed local reading/pixel review, barred file changes and external-site calls, and asked for uncertainty. All 18 calls exited 0 and returned scores. Image replies report pixel review and describe matching content. No browser fallback was needed. Logs: `agy-r2-text-N.txt.log` next to each text, and `images/agy-r2-hero-N.log` next to each image. Raw evidence is under `/tmp/citata-competitors/`; it can expire. The selected reviewer model is Gemini 3.8 Flash (High). Guesses in its replies about which model wrote the source, or claims that supplied case facts are true, were not accepted as evidence.

**SynthID remains unverified for all items.** Gemini said no real verifier was available. A model's visual guess or a missing text/metadata marker is not a watermark check. We did not claim a negative SynthID result. No cryptographic C2PA validation ran.
