We read the round-1 teardown and the full 150-row H03 file from origin/stage. We matched exact cities and company identities. Littleton is not Denver. Bothell is not Seattle. Oakland Beacon is not this Littleton firm.

For cities outside H03, no free model-answer run was obtained. Their AI status stays unknown. Ordinary search results are not new AI-answer tests.

Direct requests to many WordPress sites returned 403. The public reader used `X-Return-Format: html`. It returned HTML, rendered sitemaps, empty documents, and later 429 errors. We also used search-fetched client pages. These are mixed snapshots, not one synchronized crawl.

A sitemap count is an observed URL count, not indexed pages or unique useful content. A visible post date is not verified first publication. Blog lower bounds are not full rates. Home counters that render as zero are not business measurements.

We checked the 6 requested listing types through public search. Only positive findings appear below. All other combinations remain unknown, including Thumbtack where no firm match was verified. No source proves Goodjuju created a directory listing.

### P1. Owner path plus local pages

Management service, local pages, owner FAQ, rental analysis, and separate renter links repeat across current sites.

Cases and current footer credits support a Goodjuju delivery pattern. Shared page order suggests a reusable framework, not a proved identical template.

Client evidence: [Excellence Property Management](https://gogoodjuju.com/review-case-study-excellence-property-management-growth/), [Hallmark Property Management](https://gogoodjuju.com/case-study-hallmark-property-management/), [Iron Horse Property Management](https://gogoodjuju.com/review-case-study-iron-horse-pm-growth/), [PropertySourced Property Management](https://gogoodjuju.com/review-case-study-propertysourced-growth/), [Traverse Property Management](https://gogoodjuju.com/case-study-traverse-pm/), [Best Property Management of TN and GA](https://gogoodjuju.com/case-study-bpm-chattanooga/).

### P2. Local SEO plus review requests

Goodjuju cases combine local search work with steady review requests and GBP work. Sites show Google review proof beside owner offers.

Named client accounts support the service bundle. Current review counts vary by source. No isolated review-only effect measured.

Client evidence: [Excellence Property Management](https://gogoodjuju.com/review-case-study-excellence-property-management-growth/), [Beacon Property Management](https://gogoodjuju.com/case-study-beacon-property-management/), [PropertySourced Property Management](https://gogoodjuju.com/review-case-study-propertysourced-growth/), [Traverse Property Management](https://gogoodjuju.com/case-study-traverse-pm/), [Best Property Management of TN and GA](https://gogoodjuju.com/case-study-bpm-chattanooga/).

### P3. Landlord question clusters

Lease, screening, rent collection, maintenance, and eviction guides repeat with local details. Some clients publish several posts on one date.

Similar titles and batch dates support a shared content plan. They do not prove shared authors or automated text.

Client evidence: [Hallmark Property Management](https://gogoodjuju.com/case-study-hallmark-property-management/), [Iron Horse Property Management](https://gogoodjuju.com/review-case-study-iron-horse-pm-growth/), [Traverse Property Management](https://gogoodjuju.com/case-study-traverse-pm/), [PMI Equitas](https://gogoodjuju.com/case-study-pmi-equitas/), [OZ Realty](https://gogoodjuju.com/case-study-oz-realty-management/).

### P4. Mixed platforms and suppliers

## Ten Ranked Moves For Citata.ai

Ranks reflect expected effect on qualified owner leads. Every expected effect is a hypothesis. Apply client-site moves only within the client service area.

### 1. Track owner leads through signed doors

Add source, city, qualified-owner status, call outcome, and signed-door fields. Report exact-city AI names and cited domains separately.

Expected effect, hypothesis: Higher confidence in which work earns owner leads.

Evidence: [Hallmark Property Management](https://gogoodjuju.com/case-study-hallmark-property-management/), [Traverse Property Management](https://gogoodjuju.com/case-study-traverse-pm/).

Measure: Qualified owner leads, signed owners, and signed doors by source. Repeat the same 3-engine city prompts.

### 2. Build one owner path per real service area

For each client, connect a city page to service details, an owner FAQ, reviews, and rental analysis. Use citata.ai service pages the same way.

Expected effect, hypothesis: More relevant owner searches and more qualified inquiries.

Evidence: [Excellence Property Management](https://gogoodjuju.com/review-case-study-excellence-property-management-growth/), [PropertySourced Property Management](https://gogoodjuju.com/review-case-study-propertysourced-growth/), [Iron Horse Property Management](https://gogoodjuju.com/review-case-study-iron-horse-pm-growth/).

Measure: Qualified owner inquiries per city page. Verify the firm actually serves each place.

### 3. Pair GBP work with review requests

Check GBP facts. Ask all eligible owners and tenants for honest reviews at clear service points. Show dated review sources on pages.

Expected effect, hypothesis: More local trust and more qualified calls.

Evidence: [Beacon Property Management](https://gogoodjuju.com/case-study-beacon-property-management/), [Traverse Property Management](https://gogoodjuju.com/case-study-traverse-pm/), [PropertySourced Property Management](https://gogoodjuju.com/review-case-study-propertysourced-growth/).

Measure: New reviews, review source, map calls, and owner lead quality. Do not gate requests by sentiment.

### 4. Ship 3 owner decision tools

Build rent-versus-sell, vacancy-loss, and rental-return tools with clear inputs and assumptions. Link them from client city pages. Add an agency value tool to citata.ai.

Expected effect, hypothesis: More useful visits, links, and owner inquiries.

Evidence: [Traverse Property Management](https://gogoodjuju.com/case-study-traverse-pm/).

Measure: Tool completions and qualified owner inquiries. Test the math and mobile flow.

### 5. Publish local question clusters

Start with screening, leases, rent collection, maintenance, and eviction. Add city facts and primary source links. Give each page one clear answer.

Expected effect, hypothesis: Broader useful search coverage and more answer-ready text.

Evidence: [Hallmark Property Management](https://gogoodjuju.com/case-study-hallmark-property-management/), [Iron Horse Property Management](https://gogoodjuju.com/review-case-study-iron-horse-pm-growth/), [Traverse Property Management](https://gogoodjuju.com/case-study-traverse-pm/).

Measure: Indexed pages, qualified visits, and exact-city AI names. Use a human check for legal claims.

### 6. Show fees and owner protections

Publish fee terms, exclusions, service scope, and guarantees that the client can honor. Publish citata.ai scope and price terms too.

Expected effect, hypothesis: Better owner fit and fewer price-only sales calls.

Evidence: [Hallmark Property Management](https://gogoodjuju.com/case-study-hallmark-property-management/), [Iron Horse Property Management](https://gogoodjuju.com/review-case-study-iron-horse-pm-growth/), [OZ Realty](https://gogoodjuju.com/case-study-oz-realty-management/).

Measure: Qualified inquiry rate, sales time, and lead objections.

### 7. Publish named proof with dates

Use a named client, city, baseline, period, lead definition, source, and limits. Ask consent before citata.ai publishes its own case.

Expected effect, hypothesis: More trust in the offer and clearer evidence for AI answers.

Evidence: [Excellence Property Management](https://gogoodjuju.com/review-case-study-excellence-property-management-growth/), [Hallmark Property Management](https://gogoodjuju.com/case-study-hallmark-property-management/), [PropertySourced Property Management](https://gogoodjuju.com/review-case-study-propertysourced-growth/).

Measure: Case-assisted qualified leads. Keep door counts and review counts tied to one dated source.

### 8. Fix public listing facts

Check name, phone, address, service area, and URL across the 6 requested directories. Track found, missing, and unknown separately.

Expected effect, hypothesis: Clearer business identity across sources used in AI answers.

Evidence: [Valiant Realty & Management](https://www.featuredcustomers.com/vendor/goodjuju), [Traverse Property Management](https://gogoodjuju.com/case-study-traverse-pm/), [Hallmark Property Management](https://gogoodjuju.com/case-study-hallmark-property-management/).

Measure: Confirmed profile accuracy and source-domain changes. Directory ownership is not proof Goodjuju created it.

### 9. Test crawl access and truthful schema

Check status, canonical, sitemap, robots, and visible page facts. Add valid Organization, LocalBusiness, Service, and Article data only where it fits.

Expected effect, hypothesis: Fewer crawl faults and clearer business facts.

Evidence: [Excellence Property Management](https://gogoodjuju.com/review-case-study-excellence-property-management-growth/), [Hallmark Property Management](https://gogoodjuju.com/case-study-hallmark-property-management/), [Iron Horse Property Management](https://gogoodjuju.com/review-case-study-iron-horse-pm-growth/), [Valiant Realty & Management](https://www.featuredcustomers.com/vendor/goodjuju).

Measure: Successful public fetches and schema checks. Test llms.txt as a small option, not a promised citation fix.

### 10. Send a short video and change log

Show one work log, lead sources, review changes, AI names, and next steps. Use the same report for citata.ai clients.

Expected effect, hypothesis: Better client trust and faster decisions.

Evidence: [PMI Equitas](https://gogoodjuju.com/case-study-pmi-equitas/), [Five Seasons Property Management](https://clutch.co/profile/goodjuju-marketing), [Excellence Property Management](https://gogoodjuju.com/review-case-study-excellence-property-management-growth/).

## What Citata.ai Should Not Copy

Five Seasons describes agency-owned offsite blogs in its 2019 Clutch review. This is historical evidence, not a current link plan. It does not prove independent editorial support.

OZ blog excerpts contain draft directions in public text. Fix such text before publication. Shared topic plans still need local facts, clear sources, and a human check.

Do not copy dead store pages, stale archive dates, false zero counters, or a claimed top AI rank without its exact prompt and date.

Do not claim Goodjuju runs every current client site. PMI Equitas and Valiant credit PMW. Beacon credits Upward Engine. Supplier changes limit attribution.

No dedicated Section 8 service page was verified in this client set. Blocked inventories prevent a sitewide absence claim. This remains a research gap, not a proved market gap.
